Los pesos del modelo no se incluyen en el código. Desde la raíz del proyecto:

    python scripts/download_model.py small

Esta preparación descarga solo archivos públicos del modelo. La aplicación de consulta
no descarga archivos ni envía audio o texto. También podés copiar una carpeta de modelo
faster-whisper preparada en otra computadora y seleccionarla en Configuración.
